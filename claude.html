// guía de Claude · caso guía: El comunicado de Los Robles

De un chat a un sistema

Proyecto, skill, conectores y plugins, paso a paso. Primero con el caso guía; después con el caso que tú elijas.

// antes de empezar

Lo que necesitas.

Una cuenta de Claude. El plan gratis alcanza para todo, menos para los plugins.

nombres de los botones

Esta guía usa los nombres en inglés del centro de ayuda de Claude, consultado el 20 de noviembre de 2026. Si tu cuenta está en español, pueden verse traducidos o en otro lugar.

// el semáforo sigue vigente

Lo que subes a un proyecto o conectas con un conector pasa por el mismo semáforo de datos. Rojo sigue siendo rojo.

// 1 · proyecto

Crea tu proyecto.

Un proyecto guarda tus fuentes y tus instrucciones. No las pegas cada vez.

  1. En el menú lateral entra a Projects y pulsa + New Project.
  2. Ponle nombre: Los Robles. El nombre y la descripción son para ti; Claude no los lee.
  3. En el conocimiento del proyecto, a la derecha, pulsa + y sube las fuentes del caso.
  4. Pulsa Set project instructions, pega las instrucciones y guarda con Save instructions.
  5. Abre un chat dentro del proyecto y pega el pedido.

las trampas del caso
  • El portón (RD$3,200) es una cotización: no entra en los gastos pagados.
  • Lo recaudado se calcula con 19 apartamentos, no con 24.
  • El comunicado no nombra los apartamentos que deben.
  • La próxima reunión no tiene fecha y la pintura no está decidida.
// 3 · skill

Crea y usa un skill.

Un skill es tu método escrito una vez. Claude lo aplica cuando la tarea coincide con su descripción.

  1. En Settings → Capabilities, activa Code execution and file creation. En el diseño nuevo aparece como Create and edit files.
  2. Entra a Customize → Skills, pulsa + y luego + Create skill.
  3. Elige Upload a skill y sube el archivo comunicado-mensual.zip.
  4. Confirma que el skill quedó activado en la lista.
  5. En un chat nuevo pide: prepara el comunicado de octubre. No pegues las reglas: ya están en el skill.

skillLo que hay dentro: SKILL.md
---
name: comunicado-mensual
description: Prepara el comunicado mensual de una junta de vecinos a partir de gastos, cuotas y acuerdos. Úsalo cuando pidan el comunicado, el resumen o el informe del mes.
---

# Comunicado mensual

## Qué entregas
1. Tabla de gastos pagados con el total.
2. Tres cifras: recaudado, balance del mes (recaudado menos gastos pagados) y monto por cobrar.
3. Mensaje para WhatsApp de máximo 120 palabras, en tono cordial y directo.
4. Lista de pendientes.

## Reglas
- Usa solo las fuentes que te den. Si falta un dato, dilo y no lo completes.
- Un gasto cuenta como pagado solo si la fuente lo dice. Una cotización va en pendientes.
- Nunca nombres apartamentos ni personas con cuotas pendientes. Da solo cantidad y monto.
- Lo pendiente o por confirmar se presenta como pendiente, nunca como decidido.

## Antes de entregar
- Muestra cada suma con sus sumandos.
- Lista qué asumiste y qué no pudiste comprobar.
- Si los números no cuadran, dilo antes del mensaje.
cómo se arma un skill

Es una carpeta con un archivo SKILL.md. Arriba lleva name (máximo 64 caracteres) y description (máximo 200), que es lo que Claude lee para decidir cuándo usarlo. La carpeta se llama igual que el skill y se sube comprimida en un .zip.

// 4 · conectores y plugins

Dale acceso a tus apps.

Un conector deja que Claude lea una aplicación tuya, con tu permiso. Un plugin es un paquete de skills y conectores ya armado.

conector · plan gratis
  1. Customize → Connectors.
  2. Pulsa +, elige uno y pulsa Connect.
  3. Sigue la autorización de esa aplicación.
  4. En el chat: botón + → Connectors y actívalo para esa conversación.
plugin · planes pagos
  1. Customize → Plugins → Discover.
  2. Elige un plugin y pulsa Add.
  3. En el chat, escribe / o pulsa + para ver sus skills.
antes de conectar algo

El conector ve lo mismo que tú ves en esa aplicación. En el taller nadie está obligado a conectar su correo ni sus archivos personales.

// 5 · tu turno

Ahora, con tu caso.

Elige el caso de tu ruta o uno propio y repite los mismos pasos.

  1. Crea un proyecto para tu caso: sube las fuentes y escribe las instrucciones.
  2. Pide con CLARO, verifica contra lo esperado y corrige.
  3. Cuando el resultado te sirva, convierte el método en un skill con el pedido de abajo.
  4. Sube el .zip en Customize → Skills y pruébalo en un chat nuevo.
pedidoConviértelo en un skill
Convierte el método que usamos en esta conversación en un skill de Claude.
Crea una carpeta con el nombre del skill y dentro un archivo SKILL.md con:
- name: en minúsculas y con guiones, máximo 64 caracteres.
- description: qué hace y cuándo usarlo, máximo 200 caracteres.
- Qué entregas, reglas y qué revisar antes de entregar.
No incluyas datos personales ni datos del caso: solo el método.
Dame la carpeta en un archivo .zip para descargar.
si el skill no carga

Pega el método en las instrucciones de tu proyecto y guarda el prompt con [corchetes] en un archivo .txt. Funciona en cualquier plan.
